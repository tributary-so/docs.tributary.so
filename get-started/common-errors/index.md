# Common Errors

Build- and runtime-error troubleshooting for integrators using the Tributary SDK and on-chain program.

## Overview

This page collects the error messages an integrator is most likely to hit — Anchor compile errors, delegate-approval failures, `next_payment_due` gating, and composable CPI reverts — and pairs each with a root-cause explanation and the smallest fix. Use it as the first stop before the full [Error Codes](https://docs.tributary.so/protocol-reference/error-codes/index.md) reference.
