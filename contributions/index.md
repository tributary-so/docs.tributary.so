# 🛠️ Development Workflow

## For Protocol Development

1. Smart contract development with Anchor (Rust)
1. SDK development with TypeScript and React components
1. Comprehensive testing (unit + integration)
1. Documentation and CLI tool updates

## For Provider Development

1. Install Tributary SDK (`npm install @tributary-so/sdk`)
1. Design user experience and business logic
1. Integrate with Tributary protocol for payment management
1. Deploy provider services with webhooks and analytics
1. Example: contribute.so for GitHub/Twitter recurring donations
